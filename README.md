# 🌾 ML-Based Farmer Crop Prediction App

An AI-powered Crop Recommendation System that helps farmers choose the most suitable crop based on soil nutrients and environmental conditions. The application leverages Machine Learning to provide accurate crop recommendations, enabling better agricultural decision-making and improved productivity.

---

## 📌 Project Overview

Selecting the right crop is one of the most important decisions in agriculture. This project uses a trained Machine Learning model to recommend the best crop based on soil and climate parameters such as Nitrogen, Phosphorus, Potassium, Temperature, Humidity, pH, and Rainfall.

The application is built with **Python** and **Streamlit**, providing a simple and interactive web interface.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/vishnu-pratap-singh/ML-Based-Farmer-crop-prediction-app.git
```

### Navigate to Project

```bash
cd ML-Based-Farmer-crop-prediction-app
```

### Create Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate virtual environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux/Mac**

```bash
source venv/bin/activate
```

---

### Install Dependencies

```bash
pip install -r requirements.txt
```

---

### Run Application

For Streamlit:

```bash
streamlit run app.py
```

The application will open automatically in your browser.
